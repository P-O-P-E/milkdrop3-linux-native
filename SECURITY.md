# Security policy

## Supported versions

The latest `main` branch is currently supported while the project is pre-1.0.

## Reporting a vulnerability

Do not attach malicious presets or exploit files to a public issue. Use GitHub's private vulnerability-reporting feature
for this repository when available, or contact the repository owner privately through GitHub.

Preset and texture files are untrusted input. Reports involving parser crashes, excessive resource consumption, path
handling, shader compiler behavior, or unsafe file operations are in scope.
